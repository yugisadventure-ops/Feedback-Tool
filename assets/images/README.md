# Question Images

Place feedback form images in this folder. Reference them in your Excel template `image` column:

| image column value | Resolves to |
|---|---|
| `q1-demo.png` | `assets/images/q1-demo.png` |
| `assets/images/q1-demo.png` | same file |

After adding images, update `manifest.json` in this folder (or run `python3 scripts/build-image-manifest.py`).
