Firebase Setup

Configure your Firebase credentials in js/firebase-config.js to enable cloud storage. Without configuration, data is stored locally in the browser.

  1. Create a Firebase project at console.firebase.google.com
  2. Enable Firestore Database (start in test mode, then add security rules)
  3. Register a Web app and copy the config values into js/firebase-config.js
  4. Deploy or serve this tool — responses save to s2_feedback/config/responses
